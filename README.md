# MUSICAL-MOODS: Audio Data

This repository contains the audio data component of the MUSICAL-MOODS project, a foundational resource for training and validating AI models on complex, subjective, and unstructured human data.

**For a full overview of the project, please see the [central project hub](https://github.com/fabiopaolizzo/musical-moods).**

---

### Data Description

The data in this repository consists of the audio recordings generated by the VIVO interactive music system during each dance improvisation session. The audio is a direct, real-time response to the dancer's movements, making it a unique form of complex and noisy time-series data.

The files are provided in a standard MP3 format (**44.1kHz, Stereo, 320kbps**), ready for direct analysis.

### Potential Applications & Research Areas

This dataset is a rich resource for research in time-series analysis and signal processing. It is particularly well-suited for developing and benchmarking models in:

-   **Time-Series Analysis:** Analyzing complex, non-stationary signals for emergent patterns.
-   **Signal Processing:** Applying advanced filtering and analysis techniques to noisy audio data.
-   **Feature Engineering:** Developing novel audio descriptors for machine learning applications.
-   **Acoustic Scene Analysis:** Classifying and understanding complex sound environments.
